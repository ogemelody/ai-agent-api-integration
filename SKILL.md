# Project Skill: SDD iMessage Agent

Use this repository as a Spec-Driven Development workflow. Read the constitution before implementation, keep specification/plan/tasks synchronized, update `features.md` after each milestone, run tests before milestone commits, and keep GitHub pushes small and focused.

Safety: never commit secrets; keep Messages read-only by default; require an allowlist and explicit confirmation for sends; use offline tests by default; never claim delivery, signing, or installation without observed evidence; stop before credential or device actions.

Milestone commit subjects: `feat(m1): ...`, `feat(m2): ...`, through `feat(m5): ...`.
